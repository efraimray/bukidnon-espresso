# Bukidnon Espresso

> A warm, editorial coffee shop website inspired by the highlands of Bukidnon, Mindanao.

[![Live site](https://img.shields.io/badge/Live%20site-bukidnon--espresso.vercel.app-173f35?style=flat-square)](https://bukidnon-espresso.vercel.app/)

![Bukidnon Espresso homepage](image/home-img-1.png)

## About

Bukidnon Espresso is a responsive coffee shop landing page for a fictional highland cafe in Malaybalay City, Bukidnon. The site combines a calm, earthy visual identity with a simple browsing experience for exploring the cafe story, house favourites, customer reviews, and visit details.

**Live demo:** [bukidnon-espresso.vercel.app](https://bukidnon-espresso.vercel.app/)

## Highlights

- Responsive layout for desktop and mobile screens
- Smooth single-page navigation between the home, story, menu, reviews, and visit sections
- Interactive hero image gallery
- Autoplaying, responsive customer review slider
- Coffee-focused menu with descriptions and prices in Philippine pesos
- Table request form layout
- Accessible image alternative text and mobile navigation controls
- Warm editorial styling with Google Fonts, custom CSS variables, and highland-inspired colors

## Run Locally

This is a static site, so no build step or package installation is required.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the folder with any local static server.

For example, with the VS Code Live Server extension, right-click `index.html` and choose **Open with Live Server**.
